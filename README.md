# Kzie’s Findery POS

Custom online store and point-of-sale system for Kzie’s Findery.

## Current version

**v9 — September 17, 2026**

### Pricing rules

- **Retail Price** = supplier’s own selling price.
- **Wholesale Price** = what Kzie’s pays the supplier.
- **Selling Price** = Retail Price × 1.30.
- **Income** = Selling Price − Wholesale Price.

The POS includes a direct link to the Kzie’s Findery 2026 supplier price list from the New Sale screen.

### Included features

- Century Gothic-first interface and refined spacing
- Admin and Staff password login using private environment variables
- Live Philippine date and time
- POS and recent orders
- Products and category browsing
- Quotations
- Sales, refunds and warranties
- Customers and delivery information
- Reports with Retail, Wholesale, Selling Price and Income
- Pagination on long lists

## Security

Passwords are intentionally not stored in this public repository. Configure `ADMIN_POS_PASSWORD` and `STAFF_POS_PASSWORD` privately in the hosting environment.
